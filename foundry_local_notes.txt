Foundry Local RAG Project Notes

Foundry Local runs AI models directly on a user's device. This allows local AI applications to work without sending private documents to a cloud-hosted language model.

Retrieval-Augmented Generation, also called RAG, combines document retrieval with text generation. The application searches a local knowledge base first, then gives the relevant text to the language model as context.

The project uses an embedding model to convert text into numerical vectors. Similar text should produce vectors that are close together.

Cosine similarity is used to compare the user's question vector with the document chunk vectors. The highest-scoring chunks are selected as the context for the answer.

The final answer is generated by a local chat model and should be based only on the retrieved context.
